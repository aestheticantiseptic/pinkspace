# 🌸 pinkSpace - Retro Social Network 🌸

Welcome to **pinkSpace**, a fully functional, hot pink Y2K retro social media platform inspired by the desktop browser era of 2000s web design (MySpace and SpaceHey). This project combines a vintage static layout architecture with a modern real-time cloud database backend system.

## ⚡ Core Engine Features

### 🗄️ 1. Dynamic Cloud Database Backend (Supabase)
* **Real Account Registration (`register.html`):** Users can securely sign up with custom handles, email metadata profiles, and default traits that push instantly to a live Supabase server matrix database.
* **Authentication Session Logins (`login.html`):** Verifies passwords using real cryptographic tokens to unlock user session states.
* **Live Layout Customization (`index.html`):** Features a workspace entry field where users write raw HTML/CSS styling code snippets to permanently skin their profile walls to our cloud storage records!
* **8 Classic Blurb Row Items:** Users can permanently save and edit their customizable *About Me, Who I'd Like to Meet, General Interests, Music, Movies, TV, Books, and Heroes* panels straight through a database settings manager module dashboard screen (`edit-profile.html`).

### 💬 2. Thematic 13 Chatrooms Deck (`chatrooms.html`)
Swaps dynamic styling profiles, moderation bots, and rules lists instantly using clean URL parameter state query engines (`?room=goth`). 
* **Available Lounges:** Goth Room, Vampire Room, Werewolf Room, Pride Room, Fantasy/RPG Room, Gamer Lounge, Comic Collectors, Artist Space, Music Room, Wiccan Altar, Pagan Hub, Cooking/Recipes, and the Coffee Shop.
* **AOL Audio Emulation:** Converts code into classic sound waves via the browser Web Audio API when users trigger entrance door openings, departures, or message chimes. Includes sound toggles.
* **Client Moderation Bot:** Scans input stream arrays for floods and handles local administrative string parameters (`/timeout username` or `/ban username`).
* **Twitch Style Emotes Grid:** Features integrated FrankerFaceZ (FFZ) and 7TV animated image-parsing dictionary filters across profile comments and chat inputs (e.g. typing `catjam`, `omegalul`, or `kappa` displays fully animated graphics).

### 🎵 3. Desktop Sidebar Widgets
* **Profile Music Track Player:** A vintage pink-paneled audio track player deck that emulates real play/pause/skip cycles.
* **Flashing Online Indicator Badge:** Instantly flashes a green glowing Y2K "Online Now" banner overlay on profiles when session timers sync up.
* **Odometer Hit Counter:** Counts profile hits across browser load sequences, generating individual sleek black block counters with luminous neon font elements via client-side storage trackers.
* **Sparkle Trail Effect:** Streams glittering hot pink stars and cursor tokens that fall and drift down dynamically with custom physics behind the mouse.
